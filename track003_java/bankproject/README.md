# 은행 입출금 시스템

## 자바 콘솔 프로그램

### v0.0.0 
1. **사용자 추가**
    1-1. 아이디, 비밀번호, 나이, 금액 입력 및 저장
2. **사용자 조회**
    2-1. 아이디, 비밀번호 입력
    2-2. 입력받은 내용을 바탕으로 사용자 정보 조회
3. **사용자 삭제**
    3-1. 아이디, 비밀번호 입력
    3-2. 사용자 삭제 확인
4. **사용자 입금**
    4-1. 아이디, 비밀번호, 금액 입력
    4-2. 아이디, 비밀번호를 바탕으로 사용자의 금액을 업데이트
5. **사용자 출금**
    5-1. 아이디, 비밀번호, 금액 입력
    5-2. 아이디, 비밀번호를 바탕으로 사용자의 금액을 업데이트
    5-3. 금액이 부족한 경우, 출금 불가.
6. **시스템 종료**
6-1. 관련 없는 내용 입력시, 존재하지 않는 기능임을 알림.

### v0.1.0

1. Main 객체에서 반복적으로 보이는 입력부분을 UserInputView 객체로 분리하여 코드를 재사용하기 만듬.
2. User 객체에 toString 메서드 추가해서 추후에 사용할 수 있는 여지를 남겨둠.
