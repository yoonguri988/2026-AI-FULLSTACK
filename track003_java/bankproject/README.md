# 은행 입출금 시스템

## 자바 콘솔 프로그램

### v0.0.0

0. **입력 화면 추가**
   - 사용자가 데이터를 입력할 수 있는 화면
   - 상세 동작:
     - 사용자가 입력해야하는 정보와 입력할 화면을 제공
   - 예외처리:
     - 원하는 타입의 값을 입력하지 않는 경우에 무한반복으로 원하는 답이 나올때까지 이끌어냄.
     - 관련 없는 내용 입력시, 존재하지 않는 기능임을 알림.

<br>
 
1. **사용자 추가**
   - 입력한 정보를 바탕으로 사용자를 저장
   - 상세 동작:
     - 숫자 1을 입력
     - 아이디, 비밀번호, 나이, 금액 순으로 입력
     - 입력된 정보가 레파지토리에 유저 객체로 저장

<br>
 
2. **사용자 조회**
   - 레파지토리에 저장된 사용자 정보를 조회
   - 상세 동작:
     - 숫자 2를 입력
     - 아이디, 비밀번호 입력
     - 입력받은 내용을 바탕으로 사용자 정보 출력
 
<br>
 
3. **사용자 삭제**
   - 입력된 정보를 바탕으로 사용자 삭제
   - 상세 동작:
     - 숫자 3을 입력
     - 아이디, 비밀번호 입력
     - 한번더 삭제하는 게 맞는지 사용자 삭제 확인 진행
       - "Y" or "y" 입력시 사용자 삭제
       - "N" or "n" 입력시 사용자 삭제 안함

<br>

4. **사용자 입금**
   - 입력된 정보를 바탕으로 사용자 계좌 잔고에 돈을 입금
   - 상세 동작:
     - 숫자 4를 입력
     - 아이디, 비밀번호, 금액 입력
     - 아이디, 비밀번호를 바탕으로 사용자의 계좌 잔고를 업데이트

<br>
 
5. **사용자 출금**
   - 입력된 정보를 바탕으로 사용자 계좌 잔고에 돈을 출금
   - 상세 동작:
     - 숫자 5를 입력
     - 아이디, 비밀번호, 금액 입력
     - 아이디, 비밀번호를 바탕으로 사용자의 계좌 잔고를 업데이트
   - 예외 처리:
     - 사용자의 계좌 잔고에 출금 하려는 금액 보다 적은 경우, 계좌에 돈이 부족 하다고 출력

<br>
 
6. **시스템 종료**
   - 현재 실행 중인 시스템을 종료한다.
   - 상세 기능:
     - 숫자 9를 입력
