JSP Spring MVC MyBatis MySQL 8.4 Session 인증 Bootstrap5 · jQuery

팀 4명이 v1(JSP·MySQL)을 Spring Boot 3.5.16 · Thymeleaf · Oracle 18c 기반으로 리팩토링하고 AI·외부 API를 결합해 고도화한 2차 프로젝트. 팀장으로서 회사·부서·자원 예약을 담당해 Naver OCR로 사업자등록증 1장에서 6개 필드를 자동 인식(등록 소요시간 약 70% 단축), 국세청 공공데이터 API로 사업자번호·휴폐업 여부를 3중 검증(타임아웃 시 Fallback 처리), 부서 삭제 시 AI가 유사 부서를 추천하는 이관 로직, 기간 겹침(Overlap) 검증 기반 자원 예약 동시성 제어를 구현했습니다.

Spring Boot 3.5.16 Spring Security MyBatis Thymeleaf Oracle 18c Naver OCR 국세청 공공데이터 API OpenAI GPT-4o-mini

팀 4명이 v2를 JPA · JWT · Redis · OAuth2.0 기반으로 전면 리팩토링하고, 프론트엔드를 React(Redux-Saga) · Next.js · Ant Design SPA로 완전히 분리한 3차 프로젝트. 팀장으로서 회사·부서·로그인·자원·자원예약·급여관리·다국어를 담당해, Google·Kakao·Naver 소셜 로그인 후 JWT Access/Refresh Token을 발급하고 Refresh Token은 Redis에 TTL로 저장·관리하는 인증 구조를 구현했습니다. 급여 모듈에서는 국민연금·건강보험· 고용보험·소득세 등 8종 급여 항목을 전략 패턴으로 분리한 계산 엔진과, OpenAI 임베딩 기반 RAG로 급여 규정 문서를 검색해 답하는 AI 챗봇을 구축했고, 자원 예약에는 예약자 이력·경과 시간·자원 유형을 가중합해 노쇼 위험도를 점수화하는 규칙 기반 스코어러를 추가해 관리자 알림 우선순위와 GPT 안내 문구의 어조를 조정하도록 연동했습니다. 이 외에 채용·이력서 AI 검색 (RAG 기반 코사인 유사도), 근태, 평가, 프로젝트/업무, 결재 등 20여 개 업무 모듈과 한국어/영어 다국어(i18n)를 팀 전체가 함께 완성했고, 프론트엔드는 Jest 기반 리듀서·사가 테스트 41건으로 검증했습니다.
