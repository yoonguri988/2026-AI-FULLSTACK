## TODO1: CSS

1. layout
  - float : 왼쪽이나 오른쪽에 옆에 붙이기 (끊기-clear:both)
  - position : 정확한 자리를 정해서 붙이기(좌표)
  - display : 블록에 줄서기 ,속성바꾸기

2. float
  - "float: left" : 왼쪽에 배치
  - "float: right": 오른쪽에 배치
  - "clear: both" : 따라 올라가지 못하게 배치 

※ li:nth-child(숫자) -> li요소의 (숫자)번째의 요소
※ overflow: hidden, overflow:auto -> clear: both와 유사, 감싸는 상위 영역에 지정
