■2. 자바
1.    OOP? 
객체 지향 프로그래밍, 틀 기반 프로그래밍
부품 객체(클래스) 조립, 완성된 프로그램을 만드는 기법

2.  OOP특징 
- 캡다상추
캡슐화 : 외부접근 제한
다형성 : 한가지 타입으로 여러타입을 관리, 확장성이 뛰어남
상속 : 클래스의 재사용
추상화 : 핵심 기능 추출해서 만든 모델링

3.  클래스는  (        )와  (       )를 갖는다 
상태(멤버변수, 속성)와 행위(멤버함수, 기능)

4.  클래스와 인스턴스 구분
- 클래스는  (      )
- 인스턴스는  (          )
클래스는 설계도, 인스턴스는 실제로 만들어진 객체
